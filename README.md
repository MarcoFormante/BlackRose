# Black Rose Tattoo Messina

Website for a tattoo studio in Messina, Italy, developed for a real client, with a custom admin area that lets the studio manage its own content.

🌐 **Live site:** https://blackrosetattoomessina.it/

> **Note:** this is a commissioned project for a real business. The repository is public for portfolio purposes only; it is not meant to be installed or reused.

## About the project

The studio needed a site to present its artists and their work, receive contact requests, and update content on its own, without depending on a developer for every change.

## What I built

- **Artist portfolios**: galleries presenting the work of each tattoo artist
- **Contact requests**: contact form with requests stored and managed from the back office
- **Admin area** built with EasyAdmin, so the studio can update content and handle requests autonomously
- **Interactive front-end** using Symfony UX and custom Stimulus controllers
- **Reusable UI** built with Twig Components
- **Responsive design**, styled with Sass

## Tech stack

- **Back-end:** PHP, Symfony, Doctrine ORM
- **Front-end:** Twig, Twig Components, Symfony UX, Stimulus, Sass
- **Admin:** EasyAdmin

## Highlights

- Delivered a complete site, from the database to the admin, for a real client
- Designed the admin so non-technical users can manage content on their own
